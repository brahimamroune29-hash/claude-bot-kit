# من فكرة لـ workflow.json

بلوكات جاهزة، مُركّب، فحوص، و`workflow.json` تستوردو فـ n8n. دقائق.

المكان: مجلد هذي المهارة. فـ كل أمر تحت، عوّض `$SKILL_DIR` بالمسار اللي تقراه فـ «Base directory for this skill» (ولا دير `export SKILL_DIR=…` قبل).
خطة المستخدم تتكتب فـ مشروعو (`plans/…`)، ماشي داخل مجلد المهارة.

**تكلّم مع المستخدم بلغتو.** قبل ما تكتب الخطة اسألو حتى تفهم: واش يدخل (المشغّل)،
واش يطلع (الفعل)، و وين تتسجّل البيانات. سؤال ولا زوج فـ كل مرة، مع جواب مقترح.

---

## الخطوات الثلاث

### ١ · اكتب الخطة

ملف `.mjs` فيه `meta` و `plan`. الخطة قائمة بلوكات، كل واحد `[اسم, خيارات]`:

```js
export const meta = { name: 'التقاط lead', tz: 'Africa/Algiers' };

export const plan = [
  ['webhook',    { path: 'lead' }],
  ['killSwitch', {}],
  ['dedupe',     { key: '={{ $json.body.id }}' }],
  ['code',       { name: 'طبّع', code: '…' }],
  ['llm',        { name: 'صنّف', system: 'رجّع JSON…' }],
  ['branch',     { name: 'ساخن؟', when: '={{ $json.hot }}',
                   yes: [['sql', {}], ['telegramAlert', {}]],
                   no:  [['sql', {}]] }],
];
```

القائمة **خطّية**: مخرَج كل بلوك يدخل للّي بعدو. التفريع (`branch`/`route`)
**نهائي** — الاستمرار يدخل داخل الفرع نفسو.

ابدأ من `$SKILL_DIR/plans/example-lead.mjs` (انسخو لمشروع المستخدم) — مثال كامل يخدم، بدّل فيه.

### ٢ · ركّب

```bash
node $SKILL_DIR/assemble.mjs plans/my-flow.mjs
```

يعطي `workflow.json` + تقرير. ولا يرفض بسبب مكتوب.

### ٣ · استورد

n8n → **Import from File** → عيّن الـ credentials → **جرّب يدوياً قبل التفعيل**.

⚠️ الاستيراد اليدوي **يُسقط كتلة settings بصمت**. إذا تهمّك (timezone، حفظ
التنفيذات) استعمل `--deploy` بدلها:

```bash
N8N_BASE_URL=… N8N_API_KEY=… node $SKILL_DIR/assemble.mjs plans/my-flow.mjs --deploy
```

الدفع يقرا الورك فلو بعد ما يكتبو و يقارن — «دفعتُ» ماشي «وصلت».
التفعيل يبقى قرارك، من المتصفح.

## البلوكات — ١٩

| | البلوك | يدير |
|---|---|---|
| **مشغّل** | `webhook` | مدخل خارجي + **ردّ 200 فوراً** قبل أي معالجة |
| | `schedule` | `{minutes}` · `{hours}` · `{cron}` |
| | `manual` | للتجربة فقط |
| **حارس** | `killSwitch` | مفتاح إيقاف واحد من `app_config` |
| | `dedupe` | حارس التكرار — CTE ترجّع صفاً دائماً |
| | `dailyCap` | سقف يومي مقروء من القاعدة |
| | `echoFilter` | يمنع الحلقة: ردّنا يرجع كحدث داخل |
| | `businessHours` | بتوقيت IANA صريح، ماشي توقيت الخادم |
| **بيانات** | `sql` | استعلام حرّ (ينبّهك إذا الكتابة بلا CTE) |
| | `logAction` | سجل الأفعال — «واش صار فعلاً؟» |
| **منطق** | `code` | الوضع يُستنتج من الجسم |
| | `branch` | تفريع بمسارين، كل واحد خطّة |
| | `route` | Switch بمخارج مسمّاة + `else` |
| | `wait` | تباطؤ مقصود |
| **AI** | `llm` | Claude بمخرَج JSON مضمون + fallback + فرع خطأ |
| **فعل** | `http` | نداء خارجي بفرع خطأ صريح |
| | `telegramAlert` | تنبيه، الهروب مبنيّ فـ الكود |
| | `respond` | ردّ صريح على webhook |
| **مراقبة** | `watchdog` | يفحص **العرَض** لا التنفيذ |

الخيارات الكاملة لكل بلوك: `references/catalogue.md`.

## 🔴 المُركّب يرفض — ما ينبّهش

هذي مقصودة. كل وحدة كلّفت عطلاً حقيقياً:

| يُرفض | ليش | الخروج منها |
|---|---|---|
| `webhook` بلا `dedupe` | كل مزوّد يعيد الإرسال ⇒ يتعالج مرّتين (٤٢ رسالة لزبون واحد فـ ١٤ ساعة) | `meta.noDedupe = 'السبب'` |
| تفريع فـ وسط القائمة | الاستمرار بعد تفريع ملتبس — أي فرع يكمّل؟ | حطّو داخل `yes`/`no` |
| `return []` فـ عقدة Code | الفرع يموت بلا أثر ولا سبب ولا خطأ | `[{json:{empty:true,n:0}}]` + IF |
| مرجع `$('اسم')` لعقدة ما كاينش | ينكسر وقت التشغيل فقط | صحّح الاسم |
| عقدة يتيمة | فرع ميّت يُستورد أخضر و ما ينفّذ أبداً | اربطها ولا احذفها |
| أكثر من trigger | مسارات متوازية تكتب نفس الصف مرّتين | افصلهم فـ ملفّين |
| `continueRegularOutput` على HTTP | يحوّل الرفض (401/429/500) لعلامة خضراء | `continueErrorOutput` + فرع |
| سرّ مكتوب خام | يمشي فـ commit | credential |
| webhook بلا عقدة ردّ | المزوّد يستنّى ثم يعيد الإرسال ثم يسحب الاشتراك | `respondNow` (افتراضي) |

و**مخرَج تفريع فارغ ما يبقاش حفرة** — المُركّب يحطّ عقدة `وقف: <الشرط> → <الفرع>`
مسمّاة. تشوف فـ n8n وين توقّف الحدث و ليش.

**تحذير لا رفض:** غياب مفتاح إيقاف. بعض الورك فلوهات ما تحتاجوش — لكن تقرا التحذير.

## المبدأ الواحد

**العدو ماشي الخطأ الأحمر. العدو هو الأخضر الصامت.**

قبل ما تزيد بلوكاً، جاوب:

> **لو انكسر هذا، متى يُكتشف — و مَن يعرف؟**
> إذا الجواب «كي يشتكي العميل»، فهذا هو العطب — ماشي الكود.

عشان هذا كل بلوك هنا: يخرج عنصراً واحداً على الأقل، و كل توقّف لُه اسم مكتوب،
و كل نداء شبكة لُه فرع خطأ.

## التستات

```bash
node $SKILL_DIR/tests.mjs      # ٢٢ تست — تكسر كل قاعدة عمداً
```

شغّلها بعد أي تعديل على `blocks.mjs` ولا `kit.mjs`. حارس ما يطلقش أسوأ من
بلا حارس — يعطيك ثقة بلا تغطية.

## زيادة بلوك جديد

١. زيدو فـ `blocks.mjs` — دالة ترجّع `{ nodes, wires, entry, exit, width }`.
٢. سجّلو فـ `BLOCKS` تحت.
٣. زيد تست فـ `tests.mjs` يكسر قاعدتو.
٤. سطر فـ `references/catalogue.md`.

العقد لازم تجي بمواضع نسبية: `_col` و `_row`. المُركّب يحوّلهم لبكسل.

🔴 و`typeVersion` تُنسخ من عقدة **حيّة تخدم**، ما تُخمَّنش من التوثيق. نسخة
غلط تستورد بخانات ناقصة بلا أي خطأ.
