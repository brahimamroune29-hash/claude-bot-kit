# bot-kit — ابنِ شات بوت أو أتمتة مع Claude Code

مهارتان جاهزتان لـ Claude Code. تكتب له بالعربي واش تحتاج، وهو يبني:

| المهارة | تبني | تشتغل على |
|---|---|---|
| `chat-bot` | بوت محادثة يرد على الزبائن، ياخذ الطلبات، يتابع بلا إزعاج، ويحوّل لإنسان وقت اللزوم. جاهز لمتجر دفع عند الاستلام؛ للحجوزات (عيادة، أكاديمية) Claude يبنيها لك فوق نفس الأساس | واتساب، إنستغرام، ماسنجر |
| `automation` | ورك فلو جاهز للاستيراد، بحرّاس مدمجة (منع التكرار، مفتاح إيقاف، سقف يومي، فرع خطأ) | n8n |

## التثبيت (مرة وحدة)

داخل Claude Code اكتب:

```
/plugin marketplace add brahimamroune29-hash/claude-bot-kit
/plugin install bot-kit@bot-kit
```

ثم أعد تشغيل Claude Code.

## الاستعمال

افتح مجلد فارغ لمشروعك، شغّل Claude Code، واكتب طلبك عادي. أمثلة:

- «ابنِ لي بوت واتساب لمتجر ملابس، الدفع عند الاستلام»
- «ابنِ لي بوت حجز مواعيد لعيادة على إنستغرام»
- «ابنِ لي أتمتة: كي يعبّي زبون الفورم، صنّفه بالذكاء الاصطناعي وابعث لي تنبيه إذا كان جاد»

أو نادِ المهارة مباشرة: `/bot-kit:chat-bot` أو `/bot-kit:automation`.

Claude راح يسألك أسئلة قليلة على مشروعك، يعبّي بطاقة المعلومات، يجرّب البوت محلياً قبل ما يلمس زبون حقيقي، وبعدها يساعدك ترفعه على سيرفر.

## واش تحتاج

**للبوت:**
- Node.js نسخة 22.13 أو أحدث
- حساب [Wasender](https://wasenderapi.com) لواتساب
- مفتاح [OpenRouter](https://openrouter.ai) للردود (لازم حتى في التجربة المحلية)
- اختياري: مفتاح OpenAI لتفريغ الرسائل الصوتية، وصفحة فيسبوك لإنستغرام وماسنجر
- سيرفر صغير (VPS) وقت الإطلاق

**للأتمتة:**
- n8n (سحابي أو على سيرفرك)
- قاعدة Postgres مربوطة بـ n8n (للحرّاس)
- مفتاح Anthropic إذا فيها ذكاء اصطناعي

## قواعد الأمان

- المفاتيح تبقى في ملف `.env` فقط، وما ترفعه أبداً لأي مستودع.
- جرّب دائماً بـ `DRY_RUN=1` وبأرقام تجربة قبل ما تفتح البوت للكل.
- بوت واحد فقط على كل رقم: إذا عندك بوت قديم، طفّيه في نفس الدقيقة.
